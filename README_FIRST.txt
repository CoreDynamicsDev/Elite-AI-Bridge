ELITE AI BRIDGE 2.0.4

Elite AI Bridge is a free cockpit companion for Elite Dangerous. Version 2.0 is a
complete redesign: a retro command deck with a setup wizard, guided tours on every
page and an in-game overlay.

Setup installs Elite AI Bridge for the current Windows user, prepares its private
Python runtime, installs the required components including the Supertonic voice,
prepares the voice model, creates shortcuts and launches the application. The setup
wizard then walks you through Elite, your sound and your keys.

An internet connection is needed during first installation if Python, runtime
packages or the voice model need to be downloaded.

The AI co-pilot is optional. Everything else works without it.

Upgrading from 1.0.x: install over the top. Your settings, mappings and sounds in
%LOCALAPPDATA%\EliteAIBridge are kept.

The private runtime is stored under:
%LOCALAPPDATA%\EliteAIBridge\runtime
