# GitHub Publishing Checklist

- [ ] Push the current public source tree to the source repository.
- [ ] Confirm the README renders correctly and points to the public source tree.
- [ ] Confirm no secrets, private diagnostics, local configuration, or build output are present.
- [ ] Tag the source commit for the release, for example `v1.0.1`.
- [ ] Create the matching GitHub Release.
- [ ] Attach the tested `Elite_AI_Bridge_Setup_1.0.1.exe` to the Release.
- [ ] Download the EXE back from GitHub and verify it launches.
- [ ] Confirm issue templates, Ko-fi link, and documentation links work.
- [ ] Do not publish API keys, passwords, tokens, personal diagnostics, or user configuration.
