# Changelog

## 1.0.1 - 2026-09-30

Maintenance and startup release following the 1.0.0 public release.

### Included
- Restored and validated the Supertonic voice backend.
- Added the CRT-style animated startup/boot sequence.
- Added a 15-second minimum startup display while the runtime initializes.
- Improved backend process-tree cleanup on normal shutdown.
- Improved source launcher behavior, including minimized normal launch and visible diagnostics on failure.
- Cleaned the public source package of development caches, logs, and temporary inspection files.
- Updated public source, build, security, privacy, licensing, and third-party documentation.

## 1.0.0 - 2026-09-27

First public release of Elite AI Bridge.

### Included
- Core Bridge and optional AI Co-Pilot modes
- Live Elite Dangerous journal/state integration
- Navigation, trade, combat, and colonization interfaces
- Keyboard/HOTAS command mapping with conflict detection
- Required-control recommendations and Push-to-Talk setup
- Borderless/windowed in-game overlay with HUD/chat modes
- AI/voice state and command feedback
- Manual System Check and diagnostics
- Dynamic ship and combat-target artwork
- Windows installer, shortcuts, uninstall support, and persistent user settings
- Public privacy/API-key, disclaimer, licensing, and third-party documentation
- Ko-fi support link
