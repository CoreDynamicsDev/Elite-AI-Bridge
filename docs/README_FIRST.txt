ELITE AI BRIDGE 1.0.1
=====================

Thank you for installing Elite AI Bridge.

This installer installs the complete Bridge application and its local runtime
bootstrap. The first launch may take several minutes while Python components
and the Supertonic neural voice model are prepared.

IMPORTANT
---------
- Elite AI Bridge is an independent community project.
- Elite Dangerous is a trademark of Frontier Developments plc.
- AI features are optional and require the user's own OpenAI API account/key.
- Never share API keys, passwords, tokens, or other credentials.
- The in-game overlay requires Elite Dangerous to run in Borderless or Windowed
  mode. Exclusive Fullscreen does not display the overlay.

After installation, use the Start Menu or desktop shortcut to launch Elite AI Bridge.

For source code, build instructions, privacy information, and third-party notices,
see the public GitHub repository.
