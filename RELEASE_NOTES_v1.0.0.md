# Elite AI Bridge 1.0.0

The first public Windows release of Elite AI Bridge.

## Installation
Download `Elite_AI_Bridge_Setup_1.0.exe` from the assets attached to this GitHub Release
and run it. The installer creates the application runtime and shortcuts and then launches
the first-run wizard.

## Core or AI
Core Bridge works without an OpenAI API key. AI Co-Pilot is optional and uses the user's
own OpenAI API account/key.

## Overlay
Use Elite Dangerous in Borderless or Windowed mode when using the Bridge overlay.
Exclusive Fullscreen does not support the overlay.

## Before sharing diagnostics
Review support/diagnostic exports before posting them publicly. Never share an API key.

## Support development
Elite AI Bridge is free. Voluntary support for continued development:
https://ko-fi.com/eliteaibridge

## Project status
This release freezes the tested 1.0 feature baseline. Future UI redesign work is intended
to remain separate from the stable 1.0 release line.
