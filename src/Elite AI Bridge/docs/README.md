# Elite AI Bridge

Elite AI Bridge is an independent Windows companion application for **Elite Dangerous**.
It combines live game/journal information, navigation, trade and combat tools, control
mapping, an in-game overlay, voice features, and an optional AI co-pilot in a
cockpit-inspired interface.

## Installation
Run the current Elite AI Bridge installer and follow the setup wizard. The first-run
wizard lets you choose Core Bridge or configure the optional AI Co-Pilot.

## AI Co-Pilot and OpenAI
AI features are optional. Core Bridge does not require an OpenAI API key.

If AI features are enabled, the user supplies their own OpenAI API account and API key.
Elite AI Bridge does not include API service, credits, or an OpenAI subscription.
OpenAI API usage may incur charges billed by OpenAI according to the user's account,
usage, limits, pricing, and applicable terms.

Never share a secret API key, publish it, commit it to GitHub, or include it in screenshots
or support material. If exposure is suspected, revoke/rotate the key and review API usage.

See `PRIVACY_AND_API_KEYS.md`.

## Controls and Game Interaction
Elite AI Bridge can read supported local Elite Dangerous data and issue configured
keyboard/HOTAS-style inputs. Automation and AI output can make mistakes. The pilot remains
responsible for configuration and actions performed in-game.

## Support / Diagnostics
Use the built-in diagnostics/support export where available. Review diagnostic packages
before sharing them publicly.
