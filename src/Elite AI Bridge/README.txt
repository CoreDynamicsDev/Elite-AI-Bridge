ELITE AI BRIDGE 1.0.1
======================

Elite AI Bridge is an independent companion application for Elite Dangerous.

INSTALLED VERSION
-----------------
The normal Windows installation is created with the Inno Setup installer built
from the top-level Elite_AI_Bridge_Setup.iss file. After installation, launch
Elite AI Bridge from the Start Menu or desktop shortcut.

SOURCE / DEVELOPMENT BUILD
--------------------------
For an extracted source copy, double-click the top-level RUN_CURRENT_SOURCE.bat.
On the first run it creates the private runtime, installs the required packages
including Supertonic, and prepares the local Supertonic-3 voice model. Internet
access is required for first-time setup.

USER DATA / UPGRADES
--------------------
Bridge preferences, mappings, custom sounds, logs, and related user data are
stored under %LOCALAPPDATA%\EliteAIBridge and are separate from program files.
Installing a newer release does not delete those settings.

UNINSTALL
---------
For an installed copy, use Windows Settings > Apps > Installed apps > Elite AI Bridge.
User data is preserved by default.
