ELITE AI BRIDGE 1.0 RC1
=========================

Elite AI Bridge is an independent companion application for Elite Dangerous.

INSTALL
-------
Run Install_Elite_AI_Bridge.bat from the setup package.
The installer places the application in:
  %LOCALAPPDATA%\Programs\Elite AI Bridge

It creates Start Menu and Desktop shortcuts and launches the Bridge when setup completes.

FIRST RUN
---------
The setup wizard guides you through Core Bridge or optional AI Co-Pilot configuration.
AI Co-Pilot requires your own OpenAI API key. Never share that key with anyone.

USER DATA / UPGRADES
--------------------
Bridge preferences, mappings, custom sounds, logs, and related user data are stored under
%LOCALAPPDATA%\EliteAIBridge and are intentionally kept separate from the program files.
Installing a newer release does not delete those settings.

UNINSTALL
---------
Use the Elite AI Bridge uninstall shortcut in the Start Menu.
User data is preserved by default.
