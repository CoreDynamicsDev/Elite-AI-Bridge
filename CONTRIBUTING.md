# Contributing

Bug reports and feature ideas are welcome through GitHub Issues.

For code changes:

1. Fork the repository.
2. Create a branch for your change.
3. Keep unrelated generated files, virtual environments, diagnostics, and build output out of commits.
4. Test the source build on Windows before submitting a pull request.
5. Describe what changed and how it was tested.

Do not submit API keys, passwords, tokens, private logs, or diagnostic archives containing sensitive information.
